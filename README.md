# SentinelAI - AI Powered Surveillance System

## Project Overview

SentinelAI is an intelligent surveillance platform that combines Wildlife Detection and Human Anomaly Detection using Deep Learning and Computer Vision.

The system provides real-time monitoring, alert generation, and incident tracking for both wildlife intrusion and suspicious human activities.

---

## Features

### Wildlife Detection
- Detects Tiger
- Detects Leopard
- Detects Lion
- Detects Bear
- Detects Elephant
- Detects Cheetah
- Real-time alert generation
- Confidence score visualization

### Human Anomaly Detection
- Fighting Detection
- Shooting Detection
- Accident Detection
- Explosion Detection
- Vandalism Detection
- Image Upload Detection
- Video Upload Detection
- Real-time anomaly alerts
